# Windows 版界面实测参数

> 来源：用户提供的 Windows 版录屏 `录屏_uzplayer.exe_20261118220952.mp4`
> （1278×828，121 秒，10fps）+ 逐帧像素测量。
> 这份文档只记**能量出来的数字和结构**，不写猜测。

## 1. 控制栏

| 项 | 实测值 | 备注 |
|---|---|---|
| 控制栏高度 | 约 96px | 视频底部到窗口底 |
| 图标尺寸 | 视觉笔画 18–22px，图标框约 24–28px | 资源是 80×80 的 2x 图 |
| 按钮中心间距 | **56px** | 左右两侧一致 |
| 首个按钮中心 | 距左边 36px | 即按钮位从 x=8 起 |
| 按钮行中心 | 距窗口底 32px | |
| 进度条 | 左右边距 **20px**，线在栏顶往下约 22px 处，高约 4px | 已播放 `#425FFF`，未播放灰 |
| 时间文字 | `00:25:33 / 01:40:50`，14px | **始终带小时位前导零** |
| 快退 | 10 秒（图标圈内 10） | |
| 快进 | **30 秒**（图标圈内 30） | 不是 10 秒 |

**按钮顺序**

- 左：`▶/⏸` · `↺10` · `↻30` · 时间 · 标题
- 右（从右往左）：`全屏` · `音量` · `齿轮(设置)` · `音轨` · `选集` · `原画` · `1.0x`

**官方控制栏没有**：关闭按钮、字幕按钮、`⋯`（齿轮即设置入口）、常驻音量滑杆
（喇叭平时只是个图标，点=静音）。

右侧从右边界量：全屏中心距右 27px，之后每 56px 一个；文字按钮（原画/倍速）宽度按文字自适应（约 60px）。

## 2. 小弹层（倍速 / 清晰度 / 音轨 / 字幕 / 选集）

共同形态：

- **没有标题栏、没有关闭按钮**（这点和我最初的实现相反）
- 宽 **258–268px**，项高 **48px**
- 每项 = **单选圆圈**（未选空心灰、选中主色实心 + 白点）+ 文字
- 圆圈中心距面板左 17–18px，文字从 46–48px 起
- 背景深色半透明 + 圆角 8，能透出视频
- 倍速列表是**降序**（2.0x 在最上，0.5x 在最下）

**清晰度弹层**额外带副标题：每项两行，主标题（原画 / 1080P / 高清 / 标清）+ 灰色第二行编码信息
（`hevc flac 8.60Mbps`、`h264 aac 3Mbps`…），项高约 72px。

**字幕弹层**顶部多一行操作按钮：`搜索` · `+ 添加` · `调整`，每个列表项右侧还有删除（垃圾桶）图标。

## 3. 「播放设置」大面板（ConfigPopup）

- 尺寸 **602×449**
- **两栏**：左栏 145px 是分组标签，右栏是内容区
- 标题栏：`播放设置` + 右侧 `×`
- 左栏 9 个分组：`声道` `HDR/杜比` `图像` `解码` `解封装` `个性化` `快捷键` `循环播放` `定时播放`
- 点左栏切换右侧内容（不是弹新窗口）
- 右侧内容举例：
  - 「循环播放」：标题 + 4 个单选（顺序播放 / 单视频循环 / 全部循环 / 随机循环），每项带灰色说明文字，选中项整行有主色淡底
  - 「声道」：自动 / 立体声 / 双声道 / 4.0 / 5.1 / 7.1

## 4. 字幕调整面板（SubtitleSetPopup）

- 尺寸约 **466×423**
- 标题栏：`字幕调整` + 右侧 `重置` 按钮 + `×`
- 四组表单：
  1. `字幕偏移`：`延迟` 按钮 · 输入框（显示 `0.0s`）· `加快` 按钮
  2. `字幕位置`：滑杆，左端「下方」右端「上方」
  3. `大小`：滑杆，左端「大」右端「小」
  4. `字幕颜色`：7 个单选（默认/灰色/金色/绿色/红色/蓝色/紫色），**文字用对应的颜色显示**

## 5. 搜索外挂字幕（SubtitleSearchPopup）

- 尺寸 **760×387**（这才是「很大的弹窗」）
- 标题栏：`‹ 搜索外挂字幕` + 右侧 `×`
- 标题栏下：影片名（左）+ `重新搜索`（右）
- 搜索态：居中转圈
- 结果态：一行搜索框 + 蓝色 `搜索` 按钮（主色 #425FFF 实心胶囊），下面是结果列表
  （每行左侧标题、右侧 `›` 箭头）
- 底部 toast：`✓ 切换成功。`

## 6. 标题栏（自绘）

左：`▶` 图标 + 视频标题；右：`(i) 信息` · `图钉 置顶` · 分隔线 · `−` · `□` · `×`。
