# Windows 版播放器实测基线（Wine 真机，2026-11-18）

在 Wine 里跑官方 `UZPlayer.exe`，逐像素量出来的值。之前 `PLAYER-FEATURE-PARITY.md`
里那些"按 QSS 推断"的尺寸大多不准，本文是**实测**版本，改样式以本文为准。

测量条件：播放窗口 **1280×828**（标题栏 44 + 视频 718 + 控制栏 66），
屏幕 2160×1440，100% 缩放。

---

## 1. 窗口结构

| 区域 | 尺寸 | 说明 |
|---|---|---|
| 自绘标题栏 | 1280×44 | 图形 logo + 标题 + 右侧 4 个按钮（信息 / 投屏 / 最小化 / 最大化 / 关闭） |
| 视频区 | 1280×718 | 独立的子窗口（`1280x718+0+0`），不叠控制栏 |
| 控制栏 | 1280×66 | 独立 ARGB 窗口，**纯色 `#141620`**，不是渐变 |

三者不重叠：控制栏不浮在视频上，是单独一条。

## 2. 控制栏（66 px）

| 元素 | 实测值 |
|---|---|
| 背景 | `#141620`（纯色，逐像素 `(20,22,32)`） |

| 已播色 | `#425FFF` `(66,95,255)` |
| 未播轨道 | `(51,53,61)` = `rgba(228,228,228,0.15)` 叠在 `#141620` 上 |
| 滑块 | **静止时不画**（没有圆点/图片滑块） |
| 按钮行中心 | y=+35 |
| 按钮位宽 | **56px**（图标中心间距实测 56） |
| 图标视觉尺寸 | 18–22px（资产是 80×80 的 2x 图，按 24–28 绘制） |
| 首个按钮中心 | x=36（slot 从 x=8 开始） |
| 最后一个按钮中心 | x=1252（右边距 28） |

## 3. 小弹层（倍速 / 清晰度 / 音轨 / 字幕）

- 窗口固定 **320×360**，ARGB + 圆角 8 + 1px `rgba(179,193,205,0.15)` 描边。
- 位置：**底边贴控制栏顶**，**水平中心对准触发按钮中心**。
- 背景 `rgba(0,0,0,0.85)`（实测：视频 (86,130,162) → 面板内 (13,20,24)）。
- **没有标题栏、没有关闭叉**。
- 内边距 8，行从 y=8 开始。

单行项（倍速）：行高 **46**，单选圆圈中心 x=20、直径 16，文字 x=53，字号 ≈15。

双行项（清晰度/音轨/字幕）：行高 **74**，主标题中心 y=+23.5，副标题中心 y=+50.5
（副标题灰色 `(190,191,192)`、字号 ≈13）。

实测内容：

```
倍速      2.0x / 1.5x / 1.25x / 1.0x / 0.75x / 0.5x        （降序，6 项单行）
清晰度    原画  hevc flac 8.60Mbps
          1080P h264 aac 3Mbps
          高清  h264 aac 2Mbps
          标清  h264 aac 1Mbps
音轨      未知  flac stereo（选中）/ 未知  truehd 7.1
字幕      顶部按钮行：搜索（药丸高亮）· + 添加 · 调整，下方分隔线（高 56）
          不显示字幕（单行）
          日语 ASS / [外挂]sc.ass        + 右侧垃圾桶
          日语 ASS / [外挂]tc.ass        + 右侧垃圾桶
          日语 ASS / [外挂][UHA-WINGS…]  + 右侧垃圾桶（选中）
```

弹层交互（实测）：
- 点按钮打开；**再点同一个按钮不会收起**（关掉后立刻重开，视觉上没变化）。
- 点视频区 / 控制栏空白处关闭。
- **Esc 不关闭**。
- 行 hover 有高亮（官方 `item:hover`）。

## 4. 设置面板（齿轮）

- 独立窗口 **720×490**，ARGB，圆角 8，背景 `rgba(0,0,0,0.85)`，
  **在播放窗口内居中**（实测中心 = 窗口中心）。
- 标题栏高 **56**：左侧 `播放设置`（≈15px，55% 白），右侧关闭叉（中心 距右 30、距顶 30），
  下方 1px 分隔线。

左栏（宽 **178**，右侧 1px 分隔线）：

| 项 | 说明 |
|---|---|
| 声道 · HDR/杜比 · 图像 · 解码 · 解封装 · 个性化 · 快捷键 · 循环播放 · 定时播放 | 9 项，行高 **45**，首项中心 y=95.5 |

- 选中项：圆角（≈6）淡蓝底 `rgba(66,95,255,0.14)`，范围 x 12..165、高 48，文字变蓝。
- 未选中文字 `(232,232,232)`，15px。

右栏内容：分组标题（x=204，y=+35，15px），下方 1px 分隔线（y=+117），
选项从 y=+155 开始，行距 **52.5**，单选圈中心 x=217、文字 x=241。

九页内容（全部实测文案）：

1. **声道**：自动（选中）/ 立体声 / 双声道 / 4.0 / 5.1 / 7.1
2. **HDR/杜比**：兼容模式（选中，副文案"未开启的视频文件模式最多，兼容性较好，适合大多数场景下使用"）/
   HDR模式（"优化硬件HDR和杜比视界视频的亮度和色彩效果，但低性能电脑会出现黑屏、卡顿"）/
   杜比模式（"如果想体验杜比视界视频以及HDR高亮度视频，请选用这种模式播放"）
3. **图像**：四条滑杆 —— 亮度 0 / 对比度 0 / 色调 0 / 饱和度 0，右下角「重置」按钮
4. **解码**：硬解码（选中，副文案"利用电脑自身的硬件来进行解码。优点是效率高、功耗低、适合大部分视频文件…"）/
   软解码（"通过软件进行解码。优点是支持的视频格式多，对画质和音效的支持更好，但CPU能力不足，则较低会受影响"）
5. **解封装**：默认解封装（选中，副文案"默认解封装方式支持格式相对较多、也相对稳定…"）/
   原生解封装（"系统自带…，不建议切换…"）
6. **个性化**：三行数值步进器 ——
   左右箭头快进快退 `10s`、上下箭头音量调整 `5%`、ctrl+加减号缩放窗体 `10%`（各带 −/+ 按钮）
7. **快捷键**：一行「更多快捷键指南」，下接 7 行「功能 / 按键 / 开关」：
   关闭播放窗口 `Ctrl + X`、静音键 `Ctrl + M`、全屏/退出全屏 `Ctrl + Enter`、
   暂停/续播 `Space`、字幕加快/延迟0.5秒 `Shift + / Shift -`、
   老板键(隐藏窗口) `Alt + D`、上一集/下一集 `PageUp/PageDown`，开关全部为开
8. **循环播放**：顺序播放（选中）/ 单视频循环 / 全部循环 / 随机循环（各带副文案）
9. **定时播放**：两列单选 —— 按集数：播放完本集 / 播放2集 / 播放3集 / 播放5集；
   按时长：10分钟 / 15分钟 / 30分钟 / 60分钟

## 6. 复现测量的方法

```bash
export DISPLAY=:0
# 播放窗口
xwininfo -root -children | grep 极空间
# 控制栏/弹层都是独立窗口，可直接截
import -window root /tmp/r.png
convert /tmp/r.png -crop 1280x828+561+157 +repage /tmp/player.png
```

弹出窗口的尺寸直接从 `xwininfo` 读（弹层 320×360、面板 720×490），
内部坐标从截图像素扫描得出（脚本见本节命令）。
