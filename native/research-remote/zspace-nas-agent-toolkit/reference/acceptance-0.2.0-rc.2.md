# 0.2.0-rc.2 功能测试验收版

日期：2026-10-19（Asia/Shanghai）。这是第二个功能验收候选版，供测试使用，
不是正式发布版。全部业务功能尚未完成；14 项安全整改按用户要求继续暂缓。
历史安全 RC 的证据不适用于本版，不能据此认为 LAN、下载等安全限制已经实现。

## 安装与核验

解压 ZIP，保留完整 `zspace-nas-agent-toolkit/` 目录；macOS/Linux 运行
`scripts/zspace-cli`，Windows 运行 `scripts/zspace-cli.ps1` 或 `.cmd`。
六平台分别为 macOS/Linux/Windows 的 ARM64、x64；Linux 使用静态 musl。

```sh
scripts/zspace-cli --version
# zspace-cli 0.2.0-rc.2
(cd bin && shasum -a 256 -c SHA256SUMS)
scripts/zspace-cli catalog
```

Windows 用 Get-FileHash 对照 `bin/SHA256SUMS`。ZIP 外附SHA-256校验文件；
哈希仅用于完整性检查，不是发布者签名。未做代码签名/公证。
`release-manifest.json` 记录当前源码快照、六平台格式及二进制哈希，
`package-validation-0.2.0-rc.2.json` 记录实际运行与交叉构建的区别。

## 验收顺序

1. 核对版本、架构和哈希，执行help和catalog。
2. 使用独立profile，如`--profile acceptance-020rc2`，交互登录；不要复制开发凭证。
3. 先读取状态，再创建独立NAS目录及业务对象，记录ID；本地传输使用`--local-root`。
4. 按功能文档传入最新完整`expected_*`，写操作带`--yes`及相应确认字段。
5. 优先验收上述增量的状态变化、读回及清理；异步操作需查询终态，不能只看submitted。
6. 删除仅限本次对象，不清空全局回收站；结束logout并检查logged_in=false。

分享码、播放地址、Token、授权码、profile、保险箱PIN及业务口令不要写入测试反馈。
反馈附版本、架构、脱敏命令、预期/实际结果与错误码。

## 已知限制与待测

- 跨账号无专用接收账号，写入仅模拟，未发送真实共享通知；访客会话仍待补。
- 自动合集写操作暂拒绝；手动合集detach按原生语义保留全局元数据及原片。
- 云重匹配写入仅模拟，可能合并或迁移专辑；需检查返回新ID与partial。
- 智能跳过使用两份自制90秒视频验证流程，不代表真实影视识别准确率。
- 直播真机仅占位流的导入/编辑/清理，未播放媒体；远程列表抓取、周期更新、logo导出待验。
- 审阅真机仅空项目生命周期；媒体添加、任务控制和批注写入尚无真机验收。
  有转码任务的项目当前拒绝直接删除；转码输出清理、审阅分享配置与访客仍待补。
- 图片失败/被替换的候选缓存不保证自动清理，必须检查partial/applied；不能全局清缓存。
- 更多备份/恢复、Docker终端/事件/导出、硬件直通、iSCSI迁移、远程访问、独立应用和AI助手仍待补。
- 无专用Mac，Time Machine实际备份未验；GPU接口当前不可用；防火墙/现网重配写入仅模拟。
- Windows两架构与Linux ARM64尚无原生设备验收，不能用交叉构建代替运行结论。
