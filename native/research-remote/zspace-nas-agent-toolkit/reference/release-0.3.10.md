# 0.3.10 完整测试报告处置

依据 0.3.9 Windows 完整测试报告：六入口输入矩阵、真实登录、凭据落盘、自检与业务基线已通过。以下为本版增量处理。

- 登录包装层：在 .NET 后台线程同步读取一行，主线程同时观察输入完成和 CLI 退出；CLI 180 秒超时或预检提前失败后，包装层不再等待输入。后台读不持有前台线程，独立启动器按既有退出路径退出。进程内调用时，尚未完成的 Console 读取无法取消，建议 Agent 使用独立 powershell -File 会话承载登录。
- PowerShell 下载失败：退出前显式释放下载流并删除唯一临时文件，避免原生 ExitProcess 跳过 finally 导致残留。
- Unix 下载失败：error 路径显式删除当前临时文件，保留 EXIT trap 作为补充清理。
- 大文件下载：报告稳定复现仍属未闭环缺陷。现有精确范围校验不变，错误补充 HTTP 状态、期望范围、实际 Content-Range 和实际块字节数，便于下轮无需敏感日志即可定位。报告中的 HTTP 200 范围猜测尚无原始响应证据，本版不能宣称已修复 >8 MiB 下载。
- copy/move 的 to 必须为目标目录；重名策略按 rename 控制。

Docker 网络偶发错误未稳定复现，保留原错误；退出编译开销暂保留。Windows 超时与失败清理须原生复验。本机测试、六平台构建及 CDN 完整性不替代业务或 Windows 原生验收。历史对象不清理，服务端未变更。
