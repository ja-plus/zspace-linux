# 0.3.11 两份验收报告处置

核对 0.3.10 Windows thin 回归报告和两台 NAS 修复验证报告。

## 已确认并修复

- 大文件下载：实际 206 Content-Range 为 `0-8388607/总长`，缺少标准 `bytes ` 前缀。现有代码本就按 8 MiB 循环，失败根因为格式比较。现在仅规范化缺少的单位前缀；仍逐块核对精确起止、对象总长、响应块字节数、强 ETag 和跨块版本。新增 8 MiB 前后、+1 B、9.5/12/16 MiB 范围回归。offset 仍为全量重传并验证本地前缀，不承诺节省带宽。
- Windows 下载失败临时文件：在 File 字段关闭后由独立清理守卫删除原临时路径，短暂失败有限重试；成功原子重命名后的原临时路径不存在，不触碰最终目标。
- copy/move 明确拒绝整数或数字字符串 rename:0，避免设备端静默覆盖；默认仍自动改名，2 跳过，3 明确覆盖。上传/write 的冲突策略不变。
- SMART 查询 SN 去除连字符后提交，兼容报告中的 WD-WX… 显示格式。
- Docker 应用状态 N570023 映射 E_APP_NOT_INSTALLED；appstore 403 提示检查权限或显式 source:docker，不跨来源猜测同名应用。
- compose 未知 action 列出完整可用动作。
