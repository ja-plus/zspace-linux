# 0.3.7 回归报告修复

核对 0.3.6 Windows 11 / PowerShell 5.1 回归报告，确认 A、B 两项阻断。

- A：Windows 文件删除改为验证普通文件、关闭验证句柄、再调用系统文件删除。父目录仍由句柄固定；临时访问拒绝和共享冲突使用最长三秒有限重试。不存在视为清理完成。
- B：区分独立 powershell -File 启动与现有 PowerShell 内调用。独立启动在 CLI 结束、资源释放、输出刷新后调用原生 ExitProcess，使进程无需等待上游 stdin EOF；现有宿主内调用正常返回退出码。
- 保留 CLI 原生 stdin 继承，移除后台异步输入任务。T1 必须在 Windows 上对 ps1/cmd/sh 的管道与文件输入重新验证。
- 既有 cleanup_pending 修复保留，仍需实际登录后核对持久化状态。

正式验收包版本为 0.3.7。Windows 原生回归尚未执行；本机单元测试、跨平台构建和包验证不能替代 Windows 门禁。强杀宿主后的进程树回收仍有限制。ZIP 体积限制为 2.5 MiB，完整第三方许可证继续保留。
