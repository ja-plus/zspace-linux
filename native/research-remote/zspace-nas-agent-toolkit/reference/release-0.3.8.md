# 0.3.8 Windows stdin 修复

0.3.7 回归报告证明预检清理、无需 EOF 退出、宿主继续执行均已通过原生复验。剩余 T1 确认存在：继承 stdin 未能让完整启动器的子 CLI 收到授权码。

0.3.8 对显式 --auth-code-stdin 启用 RedirectStandardInput，同步读取当前 Console 输入的一行，写入并刷新子 CLI stdin 后关闭。子 CLI 保持直接输出授权事件，Agent 仍在同一会话提交一次性码；输入不进入参数、环境变量或日志。普通命令不读取输入。保留已通过的独立 -File 退出机制与进程内宿主兼容。

Windows 自检超时信息现在区分授权探针收不到输入和普通命令等待 EOF。原生复验需运行该无 NAS/OAuth 自检，并覆盖 ps1/cmd/sh × 管道/文件输入，以及真实登录。当前没有 Windows 原生执行结果，不能把本机测试或六平台构建标为 T1 已验收。

Add-Type 编译约 0.6 秒开销保留，避免改变已通过原生验证的退出路径。ZIP 继续满足 2.5 MiB 限制；解压后 3 MB 不是当前安装包硬性要求。
