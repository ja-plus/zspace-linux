# 客户端发布安全状态（2026-10-19）

当前客户端候选版本为 0.3.0-rc.1，范围及尚待原生验收的平台见 `release-0.3.0-rc.1.md`。版本更新不改变历史审计证据的日期和适用边界。
已实施 HTTPS 默认路由、独立 HTTP 降级确认、禁用自动重定向、state 状态与 NAS 绑定、机密脱敏、唯一凭据后端、注销失效标记、锁内刷新、递归参数和路径校验、响应上限、下载完整性及句柄锚定文件操作。Windows DACL 已实现和交叉检查，原生权限验收留给测试团队。

NAS 下载器的联网写操作额外要求每次明确传 `--allow-nas-fetch`；默认拒绝，不能用持久配置或单独 --yes 开启。该开关不代替 NAS 最终连接安全策略。

用户指定本次仅完成客户端发布，服务端补丁未部署且不包含在运行包中。历史审计 `audit/SECURITY-AUDIT-2026-10-19.md` 保留当时结论；当前客户端处置以本说明和发布清单为准，不宣称服务端已整改。
